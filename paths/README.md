# Learning Paths

A path is an ordered set of Markdown tasks that teaches one workflow.

## Available paths

| Path | Status | Prerequisite |
| --- | --- | --- |
| [Quickstart](quickstart/README.md) | Ready | None |

More paths can be added after the Quickstart format has been tested with
learners.

## Rules

1. Complete Quickstart first.
2. Complete tasks in filename order unless a task says otherwise.
3. Start each task with `/start-task`.
4. Finish each task with `/complete`.
5. A task is complete only when its acceptance criteria are verifiably true.
