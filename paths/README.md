# Learning Paths

Greetings, adventurer. A road is an ordered set of quests that teaches one workflow.

## Available paths

| Path | Status | Prerequisite |
| --- | --- | --- |
| [Quickstart](quickstart/README.md) | Ready | None |

More paths can be added after the Quickstart format has been tested with
learners.

## Rules

1. Begin with `/start-journey`. Run `/mentor` when you need to know where you are on the road.
2. Walk the Quickstart road first.
3. Complete quests in filename order unless a quest says otherwise.
4. Run `/start-task` from your stronghold, `<github-login>/main`. The companion
   chooses the quest, creates `<github-login>/<task-id>`, and opens its petition
   back into the stronghold.
5. Put the quest's review evidence in the petition. A human who did not author
   it glances at that evidence, not the code, and approves it.
6. Seal the approved quest with `/complete`.
7. Track each path in `progress/<github-login>/<path>.md`.
8. A quest is complete only when its criteria pass, its petition has human
   approval, and its progress status is `completed`. A merge alone is not
   enough.
9. A route either starts a project in `projects/<project-name>/` or polishes one that already exists. Polishing routes reuse that folder.
